**13. Exceptions**

- Текст в exception всегда должен быть на английском языке.
```java
throw new RuntimeException("Не удалось найти словарь", e);  <-- Неправильно: сообщение в исключении не на английском языке
```
Исключение это не просто телеграмма, которая летит сквозь слои.

У exception особое назначение- если исключение вылетит и не будет перехвачено внутри программы, то аварийно прекратит выполнение программы.  
Тогда на экране будет распечатано сообщение эксепшена, и это сообщение должно быть понятно сисадмину в любой точке планеты.  
А значит, сообщение должно быть на английском.

Интерпретация исключения и перевод его на локальный язык должны происходить там, где это соответствует архитектуре программы.  
Или не происходить вовсе, если исключение не планируется перехватывать.

**14. Нарушение правила одной операции**

Этот метод делает две разные вещи: проверяет, что слово открыто и пишет сообщение, что слово открыто
```java
public boolean isWordGuessed() {
  boolean allGuessed = true;
  <тут код который проверяет, что слово открыто>
  if (allGuessed == true) {
    System.out.print("Вы победили! Ваше слово:\n" + secretWord);
  }

  return allGuessed;
}
```
Если метод называется `boolean isWordGuessed()`, значит он должен только проверять, отгадано ли слово.  
Если он делает еще что-то сверх этого, то он нарушает правило одной операции и его название не описывает того, что *на самом деле* делает метод.  
Возможно, при этом метод еще и содержит побочные эффекты.

Метод нужно разделить на несколько, каждый из которых будет делать что-то одно: 
```java
public boolean isWordGuessed() {
  //только проверяет, что слово отгадано    
}

public void printWinMessage() {
  System.out.println("Вы победили! Ваше слово:");
  System.out.println(secretWord);
}
```

То же самое в методе `public void concealmentWord()`.  
Он делает два дела сразу: создает маску слова(создание данных) и распечатывает маску слова(представление данных).

**15. Божественные методы**

Большой метод, который делает много разного на одном уровне абстракции и нарушает тем самым правило одной операции
```java
public void processGuessing()
```

Метод нужно разделить на несколько, каждый из которых будет делать только одно дело на одном уровне абстракции.

Например, смотрим в код метода и видим в нем обособленные по смыслу блоки:
```java
public void processGuessing() {
  //куча кода до
  char letter = rawInput.charAt(0);
  if ((letter >= 'а' && letter <= 'я') || letter == 'ё') {
    for (int j = 0; j < secretWordList.size(); j++) {
      if ((secretWordList.get(j)) == (letter)) {
        displayedWord.set(j, String.valueOf(letter));
        flag = isWordGuessed();
      }
   }
  }
  //куча кода после
}
```

Выносим эти блоки в о вспомогательные методы:
```java
public void processGuessing() {
  while(...) {
    //куча кода до
    char letter = rawInput.charAt(0);
 
    if(!isRusLetter(letter)) {
      //действия при введении нерусской буквы
      continue;  
    }

    if(!isSecretWordLetter(letter)) {
      //действия если ввели букву, которой нет в слове
      continue;
    }
    //дошли сюда- значит ввели русскую букву, которая есть в слове

    openLetter(letter);  //открываем эту букву в маске
    //куча кода после
  }
}

private static boolean isRusLetter(char symbol) {  //только проверяет букву на русский алфавит
  symbol = Character.toLowerCase(symbol);  
  return (symbol >= 'а' && symbol <= 'я') || symbol == 'ё';
}

private boolean isSecretWordLetter(char letter) {  //только проверяет, что буква есть в слове
  return secretWordList.contains(letter);  
}

private void openLetter(char letter) {  //только открывает букву в маске
  for (int i = 0; i < secretWordList.size(); i++) {
    if(secretWordList.get(i) == letter) {
      //открыть в маске букву под индексом [i]    
    }
  }
}
```

```java
}

private static boolean isGameOver() {
  return  isWin() || isLose();
}
```
Использование флагов это вообще плохая практика.  
В программе можно использовать *поясняющие переменные*, которые в чем-то похожи на флаги, но это принципиально другое.
